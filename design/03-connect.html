Where your credentials go

  • Stored in CloudEagle's encrypted vault. Never in the connector code, never in logs.
  • Added to each request by CloudEagle at the last moment. The generated code can't read or copy it.
  • Only sent to api.calendly.com. Requests to any other address are blocked.

Need someone else to connect?

Send a link to your Calendly owner. They'll see the same permission list and nothing else.
